# 📊 Meta Ads Analytics Dashboard

## 🚀 Overview
The **Meta Ads Analytics Dashboard** is an interactive Power BI project designed to analyze and optimize Meta (Facebook & Instagram) advertising campaign performance. The dashboard transforms raw advertising data into actionable insights through KPI tracking, campaign analysis, and dynamic visualizations.

---

# Dataset Used

Dataset :- https://drive.google.com/drive/folders/1W9X_fyQHMGXSxh867LSdBeGynMdPD3mv?usp=sharing

# 🎯 Objectives
- Monitor ad campaign performance in real time
- Analyze audience engagement and conversion trends
- Track advertising spend and ROI efficiency
- Identify high-performing campaigns and demographics
- Enable data-driven marketing decisions

---

# 📌 Key Features
- 📈 Campaign Performance Tracking
- 💰 Ad Spend & ROI Analysis
- 🎯 Audience Engagement Insights
- 🌍 Geographic Performance Analysis
- 📊 Conversion Funnel Visualization
- 🔍 Interactive Filters & Drill-through Reports
- ⚡ Dynamic KPI Monitoring

# 📊 KPIs Implemented
- Total Ad Spend
- Total Impressions
- Click Through Rate (CTR)
- Cost Per Click (CPC)
- Cost Per Mille (CPM)
- Conversion Rate
- Return on Ad Spend (ROAS)
- Audience Reach & Engagement

# 📈 Insights Generated
- Identified top-performing campaigns with higher conversion efficiency
- Analyzed audience behavior and engagement patterns
- Compared campaign performance across regions and platforms
- Detected high CPC campaigns affecting ROI
- Tracked daily and monthly ad performance trends
